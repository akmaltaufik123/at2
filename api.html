Dokumentasi API ATEGateway

Gerbang API AI khusus oleh Akmal Taufik Enterprise.

Base URL Production

https://akmaltaufikenterprise.my/gateway/v1

Model Semasa

gpt-6-astra

Pengesahan

Authorization: Bearer ate_<YOUR_API_KEY>

Cara Pengesahan Berfungsi

Setiap permintaan mesti menyertakan kunci API anda dalam header Authorization. Dapatkan kunci anda melalui proses akaun pelanggan ATE.

Endpoint

MethodPathKeterangan
GET /models Senaraikan model yang tersedia untuk kunci anda.
POST /chat/completions Hantar perbualan dan terima pelengkapan model.

Contoh Permintaan

{
  "model": "gpt-6-astra",
  "messages": [
    {
      "role": "user",
      "content": "Hello from ATEGateway"
    }
  ],
  "stream": false
}

Contoh curl

curl https://akmaltaufikenterprise.my/gateway/v1/chat/completions \
  -H "Authorization: Bearer ate_<YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-6-astra",
    "messages": [
      {
        "role": "user",
        "content": "Hello from ATEGateway"
      }
    ],
    "stream": false
  }'

Penstriman disokong dengan menetapkan stream kepada true.

Mula Pantas

  1. Dapatkan kunci API ATEGateway anda.
  2. Set header Authorization.
  3. Gunakan Base URL production.
  4. Hantar permintaan ke /chat/completions.
  5. Pantau penggunaan melalui portal pelanggan.
